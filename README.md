# 自动化电子手册生成系统 UI Demo

这是一个纯前端演示原型，用于向领导展示“文档上传后进入后台处理、写入数据库、生成电子手册、支持多模态问答，以及补充材料更新数据库”的数据流动过程。

项目不包含真实后端能力，不会执行真实 PaddleOCR、Markdown 解析、Embeddings、数据库写入、电子手册生成或模型问答。所有流程、状态、数据分类和回答内容都由前端 JavaScript 模拟。

## 功能概览

- `index.html` 是第一层上传入口。
- 支持两个入口：
  - `上传原始文档`：进入首次构建流程。
  - `上传补充材料`：进入更新数据库流程。
- `flow.html` 是独立流程页，展示完整数据链路。
- 第 6 步 `写入数据库` 完成后出现 `打开数据库` 按钮。
- 数据库弹窗按类型展示数据分类，包括 `制度`、`流程`、`图片说明`、`表格`，补充模式下还会出现 `补充文件`。
- 第 11 步 `生成电子手册` 完成后出现 `打开电子手册` 按钮。
- 电子手册按钮会打开外部地址：
  `https://web.mxrcorp.cn/mxrszpt-web/index.html#/book?guid=A1ACBE4FA7864770AE50D1D17B409338&lan=zh`
- 第 12 步后多模态问答区域可展示模拟回答和引用来源。

## 页面结构

```text
index.html      第一层上传入口
flow.html       独立流程展示页
styles.css      全局视觉样式
script.js       首页上传入口跳转逻辑
flowPage.js     流程页动画、按钮、数据库弹窗和问答逻辑
flowState.js    纯状态模型和模拟数据
tests/          Node 内置测试
DESIGN.md       视觉设计规范
```

## 数据流程

流程页按以下顺序点亮步骤：

1. 格式分类
2. PaddleOCR介入
3. 得到Markdown
4. Embeddings接入模型
5. 资料分块
6. 写入数据库
7. 检测关联度
8. 高关联内容聚合
9. 重排序
10. 设计版面
11. 生成电子手册
12. 多模态提问

## 运行方式

在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

浏览器打开：

```text
http://localhost:4173
```

## 测试

运行全部测试：

```bash
npm test
```

当前测试覆盖：

- 默认上传流程状态。

## 演示说明

### 首次构建

1. 打开 `http://localhost:4173`。
2. 点击 `上传原始文档` 或 `查看整个流动`。
3. 页面跳转到 `flow.html?mode=initial`。
4. 等待流程自动运行。
5. 第 6 步后点击 `打开数据库` 查看分类数据。
6. 第 11 步后点击 `打开电子手册` 打开外部电子手册页面。

### 补充材料更新

1. 打开首页。
2. 点击 `上传补充材料`。
3. 页面跳转到 `flow.html?mode=supplement`。
4. 流程同样运行到数据库写入步骤。
5. 点击 `打开数据库`，可看到 `补充文件` 分类。

## 设计说明

界面遵循 `DESIGN.md` 中的视觉规则：

- 暖色画布背景。
- 珊瑚色主按钮。
- 深色产品面板。
- 克制圆角和轻边框。
- serif 大标题与 sans UI 文案组合。

## 注意事项

- 本项目是表面演示原型，不接真实接口。
- 文件上传入口只用于演示，不读取真实文件内容。
- 数据库和电子手册内容均为静态模拟数据。
- 如果浏览器缓存导致页面未更新，可刷新页面或在 URL 后添加查询参数。
